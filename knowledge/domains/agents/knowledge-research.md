# Research knowledge before changing it

Define the question, owning domain, applicability and version before collecting material. Inspect existing project source, accepted decisions, maintained knowledge and prior evidence. Find the primary owner of each claim: an official specification, released manual, source revision or first-party interface.

Keep findings, inference and proposed changes distinguishable. Record supporting links, the checked revision or date, uncertainty and the condition requiring refresh. Reuse an existing evidence owner when one already answers the question. Resolve conflicting claims against applicable versions and observed behavior; a copied instruction is not proof.

Use independent reading only when it has a bounded question and useful parallel work. Runtime delegation follows the owning workspace's procedure, retains task ownership and returns evidence for owner review. A delegate's completion claim cannot replace local verification.

Finish when the scoped question is answered with traceable evidence or when the remaining unknowns and their owner are explicitly recorded. Use [domain modeling](domain-modeling.md) when the finding changes terminology, and [writing for agents](writing-for-agents.md) when turning it into maintained guidance.
