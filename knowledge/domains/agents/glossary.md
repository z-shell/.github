# z-shell knowledge governance

Terms used to distinguish knowledge ownership, presentation and agent capabilities.

| Term | Meaning |
| --- | --- |
| Knowledge domain | A maintained subject area with defined responsibilities and relationships to other z-shell subjects |
| Editable source | The authoritative content maintained by its declared owner |
| Delivery copy | A consumer-facing representation derived from an editable source |
| Organization policy | Mandatory rules applying across z-shell repositories |
| Scoped guidance | Detailed rules selected for an applicable task and affected paths |
| Runbook | A maintained, repeatable organization procedure |
| Agent role | A defined task responsibility and output contract for an agent |
| Skill | A discoverable agent capability with a task-specific workflow |

Use knowledge domain for subject ownership and skill for an agent capability. Use editable source for authoring authority and delivery copy for its maintained presentation. Avoid calling a skill marketplace a knowledge domain or treating a presentation URL as proof of authoring ownership.
